- Pure functions in `src/`, no classes; the UI receives its side effects (PDF, save) as injected dependencies.
- The preview and the PDF come from the same SVG pages.
- Cube drawing works in cubie-edge units; the layout applies the scale.
- Static client-side build with Vite, deployed to GitHub Pages.
- Every user-facing text comes from an injected typed dictionary; each language has its own generated page, committed and checked by snapshot tests.
